# Как пользоваться репозиторием

## Добавление и изменение документации

Вся документация хранится в виде текстовых файлов.

### Создать новый документ

1. Перейдите в нужный раздел репозитория.
2. Нажмите **Add file** → **Create new file**.
3. Укажите имя файла.
4. Заполните документ.
5. Нажмите **Commit changes**.

### Изменить существующий документ

1. Откройте нужный документ.
2. Нажмите **Edit** (значок карандаша).
3. Внесите изменения.
4. Нажмите **Commit changes**.

---

## Как выбрать раздел

Перед добавлением информации определите, к какому типу она относится.

| Если нужно...                             | Раздел         |
| ----------------------------------------- | -------------- |
| Описать термин                            | `glossary`     |
| Описать технологию, инструмент или подход | `knowledge`    |
| Описать бизнес-процесс                    | `processes`    |
| Написать инструкцию для пользователя      | `playbooks`    |
| Написать техническую инструкцию           | `runbooks`     |
| Описать сервис-модуль                     | `services`     |

---

## Общая и проектная документация

Используйте корневые разделы репозитория для информации, общей для всей компании.

Если информация относится только к одному проекту, размещайте её в каталоге:

```bash
projects/<project>/
```

Структура каталогов внутри проекта повторяет структуру корневого репозитория.

---

## Перед созданием нового документа

1. Проверьте, что похожий документ уже не существует.
2. Если информация дополняет существующий документ, обновите его.
3. Если тема новая, создайте отдельный документ.
4. При наличии подходящего шаблона используйте его из каталога `templates`.
